# Sabrina Jiang — Work Portfolio Website

Open `index.html` in a browser to preview the site locally.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder.
3. In the repository, go to Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public site URL after deployment.

The site is a single continuous page with sticky navigation and responsive layouts for desktop and mobile.
